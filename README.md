# layout-switcher

Автоперемикач розкладки EN ⇄ UK для Windows. Працює в будь-якому текстовому полі (месенджери, браузер,
редактори): глобальний хук клавіатури стежить за словом, яке набирається, і якщо воно набране не в тій
розкладці — стирає його, друкує правильне й перемикає розкладку. Живе значком біля годинника, без вікна консолі.

Версія 0.9.1. Репозиторій і релізи: <https://github.com/Danix1005/layout-switcher>. Історія змін — у [CHANGELOG.md](CHANGELOG.md). Ліцензія коду — MIT ([LICENSE](LICENSE)); словники мають
власні ліцензії ([NOTICE.md](NOTICE.md)).

## Збирання

Потрібен [Rust](https://rustup.rs).

На Windows (потрібні ще «Build Tools for Visual Studio» з C++):

```
cargo build --release
```

Готовий exe — `target\release\layout-switcher.exe`. Поруч з ним мають лежати тека `dict\` і (за бажанням)
`apps-off.txt`.

З Linux (так збираються готові пакети): потрібні ціль `x86_64-pc-windows-gnu`, `gcc-mingw-w64-x86-64` і
`binutils-mingw-w64-x86-64` (там `windres`, яким `build.rs` вбудовує іконку й маніфест).

```
tools/package.sh        # тести -> exe -> dist/layout-switcher-windows.zip і dist/release/ (exe, zip, SHA256SUMS)
```

## Тести й інструменти

```
cargo test --lib                                       # 119 тестів, працюють і на Linux
cargo run --release --example replay -- layout-switcher.log   # прогнати лог через поточний детектор
cargo run --release --example simulate -- *.log      # порівняти режими --switch на записаних логах
cargo run --release --example audit                    # які ПРАВИЛЬНО набрані слова детектор зіпсував би
cargo run --release --example audit_web                # чи не стане українське слово «адресою сайту»
cargo run --release --example terms -- my_terms.txt    # перевірити свої терміни перед додаванням у словник
```

- `replay` бере лог, записаний із `--log-words`, і показує, які рішення змінились би (нові виправлення, регресії)
  і скільки ручних виправлень стали б автоматичними. Запускай після кожної зміни детектора.
- `simulate` проганяє ті самі логи через `session.rs` у режимах `always` / `smart` / `smart-both` і показує, скільки
  було б виправлень, перемикань розкладки, слів «не тією мовою» і хибних виправлень.
- `audit` моделює правильний набір кожного слова з обох словників і з `dict/en_it.txt` — без контексту й посеред
  тексту іншою мовою. Усе, що він показує без контексту, — це зіпсований текст, тож список має бути коротким.
- `terms` підказує, які англійські терміни варто додати в `dict/en_it.txt` чи `dict/en_user.txt`, а які ні
  (бо тими самими клавішами набирається часте українське слово: `dsl` = «від», `dcs` = «всі»).

Наскрізно (справжній хук і `SendInput`) програма перевіряється під Wine: Блокнот + `xdotool` (клік — справжній, не
`click --window`: інакше Wine після появи значка в треї не вважає Блокнот переднім вікном). Пункти меню значка
під Wine перевіряються командою `wm_command <номер>`, пауза й вихід — параметрами `--pause` / `--resume` / `--exit`.
У Wine є лише англійська розкладка, тож перемикання розкладки (події `layout`) там не перевірити.

## Як працює автовиправлення

1. Хук запам'ятовує **фізичні клавіші** слова (код клавіші, Shift, CapsLock), а не символи. Тому те саме слово
   можна «показати» в обох розкладках.
2. На **пробілі / Enter / Tab** слово оцінює детектор. Основне правило: виправляємо, якщо набране **не є** словом
   поточної мови, а в іншій розкладці **є** словом тієї мови.
3. Виправлення: Backspace × довжина слова → правильний текст символами Unicode → пробіл → запит на зміну
   розкладки вікну, яке тримає фокус (`WM_INPUTLANGCHANGEREQUEST`). Через 300 мс перевіряємо, чи розкладка
   справді змінилась, і пишемо результат у лог (подія `layout`).
4. Якщо слово виправлено як **вкраплене** — англійське слово посеред українського тексту (останні слова були
   українські) — розкладка не перемикається: текст виправлено, але далі людина пише українською. Друге таке слово
   поспіль уже означає зміну мови, і тоді розкладка перемикається. Режими — параметр `--switch` (див. нижче).
5. Слово «рветься» при кліку мишкою, стрілках, Home/End/Esc, комбінаціях із Ctrl/Alt/Win, зміні вікна.

### Коли обидва прочитання — слова

Частотні списки зібрано із субтитрів, і в них повно сміття: російські слова в українському списку, англійські
слова, набрані не в тій розкладці («ьуе» = `met`, «сфе» = `cat`). Тому сама наявність у списку нічого не доводить.
Детектор розрізняє **надійні** слова: англійське — з першої 20-тисячки або додане явно (`en_it.txt`,
`en_user.txt`); українське — підтверджене морфологічним словником або додане явно. Далі:

- набране — шум із хвоста списку, а інше прочитання надійне й значно частотніше → виправляємо (`ghb` → «при»);
- надійне слово без контексту не чіпаємо ніколи («суддю», `herb`);
- якщо кілька попередніх слів були іншою мовою (≥ 3 слів, ≥ 70 %), цього досить, коли набране ненадійне або
  інше прочитання не набагато рідше: `the` посеред українського тексту лишається `the`, а «руку» посеред
  англійського стає `here`;
- якщо користувач сам перемкнув розкладку перед словом, попередній контекст не враховується;
- явно додане слово не перетворюється ніколи.

### Двобуквені слова

Для них основні словники надто шумні, тому є два короткі списки `SHORT_UK` / `SHORT_EN` у `src/detect.rs`.
Виправляємо, якщо набране не зі списку поточної мови, а результат — зі списку іншої. П'ять пар є в обох списках
(«шт»/`in`, «см»/`cv`, «ша»/`if`, «св»/`cd`, «зс»/`pc`) — їх автоматично не чіпаємо в жоден бік.
Побічний ефект правила: `db` (= «ви»), `ns` (= «ті»), `ps` (= «зі») перетворюються. Щоб захистити скорочення,
допиши його в `dict/en_user.txt`.

### Режим перемикання розкладки: `--switch`

- `smart` (типово) — вкраплене англійське слово (`sftp` посеред українського тексту) виправляється без зміни
  розкладки; у зворотний бік (українське слово посеред англійського) розкладка перемикається одразу;
- `always` — перемикати після кожного виправлення (поведінка до 0.7);
- `smart-both` — «вкраплення» в обидва боки.

На трьох логах користувача `smart` дав 49 перемикань замість 131 за тієї ж кількості слів «не тією мовою».

### Розділові знаки на краях слова

У змішаному тексті крайні `? , : . "` майже завжди є розділовими знаками речення, а не символами команди.
Тому вони читаються **по-українськи в обидва боки**: `Ghbdsn?` → «Привіт,» і `ssh?` лишається `ssh?` (а не `ssh&`).
Початковий `/` і `$` (Shift+4) та знак `№` (→ `#`) читаються за клавішами: `/etc`, `$HOME`, `C#`.

### Складені слова, числа, регістр

- Слова з цифрами й дефісом розбираються по сегментах: `ЛШЕ005` → `KIT005`, `іефке-сщташп` → `start-config`.
  Якщо хоч один сегмент — справжнє слово поточної мови (`будь-який`), слово не чіпаємо.
- Числа в UK-розкладці: `192ю168ю1ю10` → `192.168.1.10`, `12Ж00` → `12:00`, `10б5` → `10,5` («5б», «5х» — ні).
- Слово без апострофа («зявляється») розпізнається.
- Адреса сайту чи пошти, набрана в українській розкладці, виправляється: `аучютуе` → `fex.net`, `гіук"глкютуе` →
  `user@ukr.net`. Лише якщо англійський вигляд — домен із відомою зоною або пошта, а український — не слово.
- Однолітерне слово перед виправленим виправляється разом із ним: «d базу» → «в базу», «ф ищщл» → `a book`. Якщо
  перед літерою розкладку перемикали самі («диск D»), її не чіпаємо.
- CapsLock враховано окремо для кожної розкладки: в українській він діє й на х ї ж є б ю ґ, в англійській на
  `[ ] ; ' , .` — ні. «ХЛІБ», набраний із CapsLock як `[KS,`, виправляється саме на «ХЛІБ».

## Значок у треї й режим без консолі

Програма зібрана як віконний застосунок без консолі (`#![windows_subsystem = "windows"]`); `--console` відкриває
вікно з повідомленнями для налагодження. Біля годинника з'являється значок (дві накладені клавіатури на темній плитці: сіро-синя позаду, салатова попереду; сірий, коли
автовиправлення призупинено). Меню — права або ліва кнопка миші:

| Пункт | Дія |
|---|---|
| Призупинити / Відновити | пауза автовиправлення й подвійного Shift; слово, що набиралось, відкидається |
| Запис логу | вимкнено / без слів / зі словами (перед записом слів — попередження про паролі) |
| Показати теку з логом | Провідник із виділеним `layout-switcher.log` |
| Вивчені слова… | Провідник із файлами `learned_en.txt` / `learned_uk.txt` (див. «Програма вчиться на ручних виправленнях») |
| Оновлення | «Перевірити оновлення зараз» і «Перевіряти раз на добу (GitHub)»; коли є нова версія, угорі меню з'являється «Оновити до версії X…» (див. «Оновлення з GitHub») |
| Запускати разом з Windows | значення `layout-switcher` у `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`; типово вимкнено. У запис потрапляють режими `--switch` / `--injected`, але не лог |
| Вийти | завершити програму |

Керування ззовні (скрипти, `start-with-log.bat`): `layout-switcher.exe --pause | --resume | --exit`. Код виходу
0 — команду надіслано, 1 — програма не запущена. Команда знаходить вікно значка за ім'ям класу `LayoutSwitcherTray`.

Windows 11 за замовчуванням ховає нові значки в області «^» біля годинника: щоб значок був завжди на видноті,
його треба перетягнути на панель (програмно цього не зробити). Якщо Провідник перезапустився, значок
повертається сам (повідомлення `TaskbarCreated`). Якщо автозапуск указує на exe, якого вже нема (теку перенесли),
при наступному запуску запис виправляється; якщо старий exe на місці — запис не чіпається.

Паніки в обробниках хуків ловляться, а консолі нема, тож їх видно лише в лозі (подія `panic`).

## Оновлення з GitHub

Програма сама нічого не ставить: вона лише перевіряє, чи є новіший реліз, а встановлює його після вашого підтвердження.

- **Коли перевіряє.** Раз на добу (перша перевірка — через ~45 с після запуску) і за пунктом меню «Оновлення → Перевірити
  оновлення зараз». Автоматичну перевірку вимикає пункт «Перевіряти раз на добу»; тоді програма не надсилає в мережу нічого.
  Один запит `GET https://api.github.com/repos/<власник>/<репозиторій>/releases/latest` із заголовком `User-Agent:
  layout-switcher/<версія>`: ні набраного тексту, ні даних про комп'ютер не передається (GitHub, як і будь-який сервер,
  бачить IP-адресу).
- **Що відбувається після «Оновити».** Вікно показує початок опису релізу й питає підтвердження. Далі: завантажується
  `SHA256SUMS`, потім `layout-switcher.exe` з того самого релізу; перевіряються адреса (лише `https://github.com/<власник>/<репозиторій>/releases/download/…`),
  розмір, ознака exe та SHA-256; файл записується поруч (`.new`) і перечитується; запущений exe перейменовується в `.old`,
  новий стає на його місце й запускається з `--after-update=<pid>` (чекає, поки стара копія завершиться). `.old` видаляється.
- **Що це дає і чого не дає.** SHA-256 із релізу захищає від пошкодженого чи обірваного завантаження і від підміни файлу
  «посередині». Він не захищає, якщо зловмисник керує самим репозиторієм (тоді він підмінить і exe, і суми). Тому репозиторій
  варто захистити двофакторною автентифікацією, а за потреби додати підпис релізу (Ed25519) — це окрема робота.
- **Якщо теку програми захищено від запису** (наприклад, `Program Files`), програма запропонує відкрити сторінку релізу,
  щоб завантажити пакет вручну.
- **Словники змінились?** Тоді автор релізу додає до опису рядок `[full-package]` — програма не оновлюватиме одним exe, а
  відкриє сторінку з повним пакетом (`layout-switcher-windows.zip`).
- **Адреса репозиторію** береться з поля `repository` у `Cargo.toml` на етапі збирання (зараз
  `https://github.com/Danix1005/layout-switcher`; з заповнювачем `OWNER` перевірка вимкнена). Регістр літер у
  `власник/репозиторій` не важливий. Налаштування зберігаються в `HKCU\Software\layout-switcher` (`UpdateCheck`, `LastUpdateCheck`).
- **Перевірка без GitHub.** Збірка `cargo build --release --features update-test` читає змінні `LS_UPDATE_API` (адреса «останнього
  релізу»), `LS_UPDATE_AUTOYES`, `LS_UPDATE_DELAY`, `LS_UPDATE_POLL` і дозволяє http — так оновлення перевірялось на локальному
  сервері під Wine. У пакет така збірка не входить.

## Випуск нової версії

1. Підняти `version` у `Cargo.toml`, додати розділ `## X.Y.Z` у `CHANGELOG.md` (його текст стане описом релізу; якщо
   змінились словники — додати в розділ рядок `[full-package]`).
2. Закомітити й запушити в `main`: `git push origin main`. Увага: пуш у `main` з новою версією — це вже випуск.
3. `release.yml` побачить, що релізу `vX.Y.Z` ще нема, перевірить, що `repository` у `Cargo.toml` вказує на цей
   репозиторій, запустить тести, збере `layout-switcher.exe`, `layout-switcher-windows.zip`, `SHA256SUMS`, створить тег
   `vX.Y.Z` і реліз. Програми в користувачів побачать його при найближчій перевірці. Пуш без зміни версії нічого не
   випускає; тег `vX.Y.Z`, запушений вручну, теж запускає випуск.

## Ручне виправлення: подвійний лівий Shift

Двічі швидко натисни й відпусти **лівий Shift** (натискання ≤ 350 мс, пауза ≤ 500 мс, між ними жодної іншої
клавіші чи кліку; Shift+літера не рахується). Спрацьовує перше з трьох:

1. **слово, яке зараз набираєш** — перемикається в іншу розкладку;
2. **щойно набране слово** (після пробілу/Tab, до наступної клавіші чи кліку) — друкується заново. Після
   автовиправлення це «скасувати»; ще раз — і знову виправлено;
3. **виділений фрагмент** — переклад «по клавішах» через буфер обміну (Ctrl+Insert → Shift+Insert, вміст
   буфера повертається). Не діє в терміналах, PuTTY/WinBox, менеджерах паролів; ліміт 5000 символів.

Pause/Break — запасна клавіша з тією ж дією.

### Програма вчиться на ручних виправленнях

- Слово, яке ви перенесли подвійним Shift (будь-яким із трьох способів) і яке словники не знають у жодному
  прочитанні (`LuxOpt`, `SiTime`, прізвища), запам'ятовується — наступного разу воно виправиться саме.
- Подвійний Shift одразу після автовиправлення («скасувати») запам'ятовує набране як справжнє слово — більше його
  не чіпаємо.
- Запам'ятовується, коли ви пішли далі (почали наступне слово); другий Shift на тому самому слові скасовує навчання.
  Не вчаться: справжні слова іншої мови (`сім` ↔ `csv`), слова до 3 символів (крім «скасувань»), схожі на пароль,
  набране в терміналах і менеджерах паролів. Backspace не вважається сигналом.
- Файли: `%APPDATA%\layout-switcher\learned_en.txt`, `learned_uk.txt` (меню → «Вивчені слова…»). Зайве слово можна
  видалити — зміни діють після перезапуску програми. Оновлення програми цих файлів не чіпає.

## Віддалені підключення (RDP, AnyDesk, TeamViewer, віртуальні машини)

Клавіші, набрані у вікні віддаленого доступу, йдуть на **інший комп'ютер зі своєю розкладкою**. Локальний
перемикач її не знає й перемкнути не може, тому:

- **у вікнах клієнтів віддаленого доступу локальний екземпляр не втручається** (список — у `src/apps.rs`);
- щоб набір виправлявся на віддаленій машині, **запусти layout-switcher там** — у самому сеансі. Один екземпляр
  на сеанс Windows; у кожному сеансі RDP може працювати свій.

На машині, якою керують віддалено, клавіші можуть надходити як програмний ввід. Режим `--injected=auto`
(типовий) сам починає його обробляти, якщо від запуску не було жодного фізичного натискання; `accept` — обробляти
завжди; `ignore` — ніколи.

Ще не зроблено: виправлення «з локального боку», коли на віддалену машину нічого поставити не можна.

## Файли поруч з exe

- `dict\` — словники (обов'язково).
- `apps-off.txt` — застосунки, де перемикач не втручається взагалі: по одному імені exe на рядок
  (`Code.exe` або просто `code`), `#` — коментар. Сюди варто додати IDE й ігри.
- `dict\en_user.txt`, `dict\uk_user.txt` — свої слова, по одному на рядок. Таке слово вважається надійним.
- Вивчені слова — не тут, а в `%APPDATA%\layout-switcher\` (див. «Програма вчиться на ручних виправленнях»).

## Діагностика

`layout-switcher.exe --log` (або пункт меню значка) пише `layout-switcher.log` поруч з exe, а якщо там писати не можна — в `%LOCALAPPDATA%\layout-switcher`. Рядок — час у мс, подія, пари `ключ=значення`:

| Подія | Що означає |
|---|---|
| `start` | версія, `via` (`args` / `tray`), розміри словників, розкладки, `remote_session`, режими `injected` і `switch` |
| `enabled` | пауза (`on=0`) / відновлення (`on=1`) з меню значка чи `--pause` / `--resume` |
| `stop` | запис логу вимкнено з меню |
| `tray`, `tray_icons` | значок створено; чи завантажились іконки з exe |
| `panic` | паніка в обробнику (текст замасковано) |
| `fg` | нове переднє вікно; `focus_exe` — якщо поле вводу належить іншому процесу; `mode=off:…` — не втручаємось |
| `word` | слово: `cur`, `ctx`, `len`, `verdict` (`fixed`/`known`/`unknown`/`short`/`nonword`/`no_lang`), `sw=1` — користувач сам перемкнув розкладку, `emb=1` — вкраплене слово (розкладку не чіпали) |
| `layout` | перевірка після виправлення: `want`, `got`, `ok` |
| `manual` | ручне виправлення: `src`, `kind` (`word`/`last`/`selection`), `auto` — що вирішив би автомат |
| `manual_noop` | ручне виправлення не знадобилось або неможливе: `reason` |
| `undo` | Backspace/Ctrl+Z до 4 с після автовиправлення — ознака хибного спрацювання |
| `injected` | режим `auto` увімкнув обробку програмного вводу |
| `stats` | раз на 10 хв: скільки натискань фізичних і програмних, скільки разів перевстановлено хуки |

`--log-words` додає самі слова (`typed`, `other`). **У лог можуть потрапити паролі**: Scroll Lock ставить лог на
паузу, а для терміналів, PuTTY, WinBox, VPN, віддаленого доступу й менеджерів паролів слова не пишуться ніколи
(лише `masked=1`). Токен, схожий на пароль чи ключ (цифра, дві літери поспіль, довжина від 8 або спецсимвол),
не пишеться ніколи: `masked=secret`. Пароль із самих літер так не впізнати, тож після аналізу лог варто видалити.

## Словники

Усі три відтворюються з першоджерел байт у байт.

- `dict/en.txt`, `dict/uk.txt` — частотні списки з
  [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, CC-BY-SA 4.0):
  англ. від 50 входжень, укр. від 2. Порядок рядків — частотність (ранг 0 = найчастіше).
  Збирання: `tools/build_freq_dicts.py`.
- `dict/uk_forms.fst` — індекс ~3,4 млн українських словоформ зі словника LibreOffice `uk_UA`
  (Andriy Rysin, проєкт [dict_uk](https://github.com/brown-uk/dict_uk), MPL 1.1), разом із варіантами без
  апострофа. 3,5 МБ, завантажується миттєво. Як ціль виправлення використовується для слів від 5 літер, як
  підтвердження «це справжнє слово» — для будь-яких. Збирання — кроки в шапці `tools/build_uk_forms.py`
  (стандартний `unmunch` пропускає частину прапорців, тому є свій розгортач `examples/expand_hunspell.rs`).
- `dict/en_it.txt` — ІТ- й мережева лексика (543 терміни). Термін звідси ніколи не перетворюється на українське
  слово, а набраний в UK-розкладці повертається. Двобуквені терміни сюди не додаються.

## Відомі обмеження

- Поля паролів програма не розпізнає. Не набирай паролі при `--log-words`.
- Вікна, запущені від адміністратора, хук звичайного процесу не бачить.
- У редакторах з автодоповненням дужок і лапок (IDE) кількість Backspace може не збігтися — додай їх в `apps-off.txt`.
- Подвійний Shift у продуктах JetBrains відкриває «Search Everywhere».
- Значок за замовчуванням потрапляє в область «^» (Windows 11) — його можна перетягнути на панель.
- Після автовиправлення в застосунках на WebView2 (новий Teams) розкладка раніше не перемикалась; з 0.6 запит
  іде вікну з фокусом — логи 0.9.0 підтвердили, що в Teams це працює.
